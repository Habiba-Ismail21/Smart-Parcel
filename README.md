#   Smart Parcel Delivery System


<p>

This project is a console-based Parcel Delivery Management System built using C++. It allows an admin to efficiently manage parcel shipments through various stages: adding new parcels, marking deliveries, canceling shipments, and searching parcels by ID or region.

Key features include:

1.Priority-based delivery queue: Parcels are managed in a queue sorted by priority (High, Medium, Low) ensuring urgent shipments are delivered first.

2.Delivered shipments tracking: Delivered parcels are stored separately for record-keeping.

3.Binary Search Tree (BST): Used to organize parcels by region, city, and zone for fast hierarchical searching and display.

4.Stack with reverse operation: Supports batch operations such as reversing delivery order temporarily without affecting the main queue.

5.Robust input validation: Ensures all user inputs (shipment IDs, regions, cities, zones, priorities) are valid and consistent.

5.User-friendly menu: Provides an intuitive interface for admins to perform all operations easily.

This system demonstrates core data structures-queues, stacks, and BSTs-in a practical application, showcasing how they can be combined to build an effective parcel management solution.
</p>
